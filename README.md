# 工学题册 · 工业机器人笔试

适配手机和电脑的纯静态刷题页，为2026年第五届全国仪器仪表行业职业技能竞赛“工业机器人系统操作员S赛项”备考。

## 使用

- 顺序/乱序练习，按题型、知识模块筛选；支持背题模式、题目搜索、笔记与答题卡。
- 自动保存学习进度，答错自动加入错题集；错题答对后保留，确认掌握后手动移出。
- 收藏题目，错题和收藏均可单独顺序/乱序重练。
- 60分钟模拟考试，支持跳题、标记待检查、15分钟提醒、到时交卷、评分与逐题复盘；刷新及后台不暂停计时。
- 本地保存，JSON导出/导入备份，支持深色模式、大字阅读和离线缓存。
- 做题界面固定单屏，题干、选项、反馈与翻题操作常驻；解析、笔记与手机答题卡通过弹层查看。
- 600道题逐题学习解析：计算题说明代入过程，判断题说明关键条件，题库疑点与原答案分开标注。
- 模块支持推荐提分顺序、题量优先、原始顺序，排序偏好自动保存；提分排序是学习建议，不是官方抽题概率。

默认模拟题量为50道单选＋50道判断，是练习预设，**不是已公布的正式题量**。两类题各占50分，正式知识模块比例及组卷参数没有公开。模拟按答对计分，未答/答错0分，单题计分细则尚未公开。

## 内容与规则依据

题目来自用户提供的2026年9月公开《工业机器人系统操作员S赛项理论题库》（`笔试.pdf`）：单选300题、判断300题。题干、选项和原参考答案保留，清理了分页页眉及排版空白，并附原题编号与PDF页码。

规则依据新提供的《理论知识竞赛规程》《工业机器人系统操作员S赛项竞赛规程》及职工组平台主要设备技术标准。理论闭卷机考60分钟、满分100、单选和判断各占50分；理论占总成绩20%。这三份指导性PDF没有替换题库。

知识模块为学习用途的内容归类，不代表官方的题量分布。原题/答案疑点单独提示，按**文件原参考答案**判分，未冒称组委会勘误。学习解析由知识点核对整理，不是官方解析，也不代表组委会逐题校订结论。本站是备考工具，不是官方考试系统。代码不含未公开正式试卷或组卷参数。

解析源文件为`explanations.tsv`，执行`python3 scripts/build_explanations.py`生成静态`explanations.js`。参考核对资料包括[OpenCV图像滤波文档](https://docs.opencv.org/4.13.0/d4/d86/group__imgproc__filter.html)、[PyTorch卷积文档](https://docs.pytorch.org/docs/stable/generated/torch.nn.modules.conv.Conv2d.html)、[Siemens过程映像说明](https://docs.tia.siemens.cloud/r/en-us/v20/functional-description-of-s7-1200-cpus-s7-1200/memory-areas-s7-1200/system-memory-s7-1200/process-image-input/output-s7-1200/basic-principles-of-process-images-s7-1200)等。链接用于相关概念核对，不表示每题均来自这些文档。

## 本地运行

无需构建、依赖或API密钥。使用任意静态服务器即可：

```sh
python3 -m http.server 8000
```

访问 `http://localhost:8000`。GitHub Pages直接从`main`分支根目录发布；所有资源均为相对路径，可部署到仓库子目录。

## 校验

```sh
node --test scripts/core.test.cjs
node --check app.js
```

`scripts/prepare_bank.py`是题库提取来源脚本，重跑需把原PDF提取文本放在项目父目录的`tmp/theory-extracted.txt`。部署文件已包含`bank.js`和可供检查的`bank.json`，网站运行不需要原PDF和Python。

## 学习数据

记录保存在浏览器`localStorage`的`gongxue-robot-study-v1`项下，不上传服务器。不跨设备自动同步，请在“我的”中导出/导入。导入合并错题、收藏、笔记和历史，相同题目统计采用较新记录，不重复累加；不会覆盖当前进行中的考试。浏览器清理网站数据会删除记录。

离线支持依赖浏览器Service Worker：首次成功联网后可用。更新采取联网优先，离线回退缓存。题库和判分代码属于静态资源，适用于自测，不提供防作弊能力。
